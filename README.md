# Zlooyear LLC

Corporate website for [zlooyear.com](https://zlooyear.com) — a technology consulting company specializing in web development, AI integration, and software engineering.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide Icons

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` — Next.js pages and routes
- `src/components/` — Reusable UI and layout components
- `src/lib/` — Data, constants, utilities, and metadata helpers

## Contact Form

The contact form is frontend-only. Backend email integration is marked with TODO comments in `src/components/ui/ContactForm.tsx`.
